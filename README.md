## 💡 О приложении

**SearchGitKiller App** — это мобильное приложение-компаньон для одноименного веб-сервиса. Оно переносит всю мощь семантического поиска проектов на GitHub прямо в ваш смартфон. 

Находите нужные репозитории, читайте их описания и сохраняйте идеи для своих будущих проектов в любое время и в любом месте, используя лишь интуитивное описание функционала.

## 🚀 Возможности мобильной версии

*   📲 **Native-опыт:** Плавные анимации и быстрый отклик, оптимизированные под мобильные устройства.
*   🧠 **Умный алгоритм в кармане:** Полноценный доступ к нейросетевому поиску без урезания функционала.
*   🌙 **Темная тема:** Стильный дизайн, который бережет зрение и экономит заряд батареи (идеально вписывается в общую стилистику проекта).
*   ⚡ **Эргономичный UI/UX:** Управление одной рукой, удобный скроллинг выдачи и быстрый доступ к деталям репозитория.
