## 💡 About the program

**SearchGitKiller App** — This is a desktop application for the web service of the same name. It brings the full power of semantic search for GitHub projects to the convenient format of a standalone desktop application. 

Находите нужные репозитории и сохраняйте идеи для своих будущих проектов, используя лишь интуитивное описание функционала, без необходимости постоянно держать открытой вкладку в браузере.

## 🚀 Desktop version capabilities

*   🖥️ **Native Experience:** Fast response, smooth performance, and seamless integration with the operating system thanks to the performance of Rust.
*   🧠 **Smart algorithm:** Full access to neural network search (Python) directly from the program window.
*   🌙 **Dark Theme:** A stylish design in dark tones that is easy on the eyes and fits perfectly with the aesthetics of the project.
*   ⚡ **Productivity:** The most convenient interface for working with a keyboard and mouse, quick access to repository details and copying links.
